# Armaments (M9a)

How arms, armaments and effects fit together. The rules below are fixed; the code that enforces them is listed so they stay in one place.

## Data
- **WeaponArmData**: an arm type. `armamentSlots` (1-3) says how many armaments it can carry (rarer arms get more). Current values: Red 1, Blue / Green / Ember 2, Purple / Piercer 3.
- **ArmamentData**: `id`, name, `icon`, `rarity` (Common / Rare / Epic / Legendary), `priceTier` (1-5), `tags` (Speed, Homing, Pierce, Bounce, Auto, Damage, FireRate, Status), `maxStacks`, `modifiers` (stat changes) and `effects` (behaviour).
- **ArmInstance**: a run-time arm: the arm type plus its armaments. Assets are never modified at run time.
- **Max stacks**: the most copies of one armament a single arm can carry (a second arm can carry its own copies).

## Stat order (StatCalculator)
Final stat = base -> all flat adds -> all percent multipliers (each multiplies: `+25%` = x1.25, two of them = x1.5625). Ammo multipliers apply later, when the bullet is fired.

## Effects (ArmEffect)
A shared, stateless asset with these hooks; all default to "do nothing":
- `ModifyShot(ref ShotProperties shot, int stacks)`: adds the effect to the per-bullet properties. Called once per DISTINCT effect asset with the number of copies (stacks) across the arm's own effects and all its armaments.
- `OnHit` / `OnBeamHit`: per-hit reactions (burn, stun).
- `Describe(int stacks, List<string> lines)`: generated description text.

Stat-only armaments (Velocity, Damage, Fire Rate, Extra Projectile) are plain `StatModifier`s and need no effect.

| Velocity | Common | Speed | 4 | +25% bullet speed per copy |

The earlier test armaments (Damage, Fire Rate, Extra Projectile, Burn, Stun) are still in the registry.

## Interaction rules (fixed)
Implemented in `Projectiles/ProjectileRules.cs`, unit-tested in `M9aTests`.
1. **Pierce is used up before a bullet stops.** Hitting an enemy with pierce left consumes one pierce and the bullet keeps flying. With none left, the enemy hit stops the bullet.
2. **Ricochet counts only wall/obstacle bounces.** A wall or obstacle hit with bounces left reflects the bullet (about the surface normal) and spends one bounce. An enemy hit never spends a bounce, and a wall hit never spends pierce. A bullet with pierce AND bounces uses pierce on enemies and bounces on walls.
3. **Homing re-targets after every bounce or pierce.** A homing bullet keeps its target until it dies, was already hit, or drifts out of range; after each pierce or bounce it picks a new one (nearest live enemy not yet hit, inside the forward cone and range).
4. Breakable obstacles take the bullet's damage before it bounces or stops. Beams (Laser) ignore pierce, ricochet and homing.
5. Auto-fire only fires the arm while it is not selected, at a target inside its slot arc and within the bullet's reach; beam ammo never auto-fires.

## Descriptions
Generated by `ItemDescriber` from the data: rarity and tags, one line per stat modifier ("+25% bullet speed"), each effect's `Describe`, and "Max N per arm". Adding an armament never needs text to be written.

## Saving
Saves store armament IDs only (asset names), so new fields need no save-version change. `ArmSave.armamentIds` has one entry per slot of that arm. When a save holds more armaments than the arm now has slots (or over the stack limit), the extras return to the armament inventory with a warning.

## Debug tools
- **F1 / D-pad up: give + equip.** Gives you the armament shown in the debug overlay (any armament in the registry) and equips it on the selected arm's first empty slot. The overlay says why when it cannot (no arm selected, slots full, stack limit).
- **F2 / D-pad down:** unequip the last armament (back to the inventory). **F3, F4 / D-pad left, right:** pick the previous / next armament of the whole catalog.
- **F6: toggle bullet paths.** Cyan = straight flight, green = homing steer, yellow X = pierce, magenta X = ricochet, red X = bullet stopped. Costs nothing while off.

## Feedback
Ricochet and pierce use the M8.6 particle presets and camera shake, and a bullet stopping on a wall puffs debris. The counts and shake strengths are on `FeedbackTuning` (Armaments section).
