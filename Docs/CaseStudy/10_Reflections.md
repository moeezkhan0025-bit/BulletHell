# 10 Reflections (template - to be answered in my own words)

This file is intentionally empty of answers. Each heading has guiding questions; write the answers yourself, in your own voice,
ideally soon after a milestone while it is fresh. Delete the questions you don't want to answer; add your own.

## 1. Why I changed how I build games
- What was my workflow before (hand-developing with some scripting help)? What was slow, painful or limiting?
- What made me try agent-driven development? What did I expect, and what happened instead?

## 2. The first week
- What surprised me most in the first milestones (M0 to M3)?
- Which moment made me trust the agent more? Which made me trust it less?

## 3. What I learned about working with an agent
- What did I learn about writing specs (CLAUDE.md) that I would not have learned otherwise?
- What kinds of tasks did I hand over easily, and which did I keep for myself? Why?
- When did plan mode, milestones or review gates save me? When did they just slow me down?

## 4. Judgment calls
- Which design decisions were mine and could not have been delegated (feel, scale, theme, what to cut)?
- Where did I overrule the agent, and was I right?
- Where did the agent push back or find a problem I had missed?

## 5. Mistakes and recoveries
- What went wrong (bugs, wrong assumptions, lost work, tooling trouble)? How did I notice?
- What would I change in my process so it is caught earlier next time?

## 6. Learning and skill growth
- What did I learn about game architecture, Unity, tools or art pipelines by reviewing the agent's work?
- What do I understand better than before? What do I understand less, because I did not write it myself?

## 7. Arcade games specifically
- What about arcade-style games (tight loops, tunable numbers, feel) suits agent-driven development well?
- What does it handle badly (game feel, juice, art direction, balance)? How did I compensate?

## 8. Cost, time and quality
- Roughly how long did each stage take compared with how I would have done it alone? (see 09_Metrics.md)
- Was the code quality good enough to keep building on? What needed rewriting?

## 9. Advice
- What would I tell another solo developer starting this way tomorrow?
- What would I do in the first day, the first week, and never do again?

## 10. What's next
- What do I want to build or learn next with this workflow?
- What would make me stop using agents for some part of the work?
